10 — Case: document intake and verify (requirements)

Problem

Cross-department files land in Drive/Teams (docx, pdf, image, csv) or the PM pastes into Cursor. Pods cannot pull from a vague pack. Need automatic classification: missing A–G vs good enough. Green + policy → auto /verified. Red → author/sender. PM only on exceptions (24).

Trigger

Run triggers §1b: A folder watch, D paste.

  • New file in Drive:/projects/{id}/intake
  • Teams/SharePoint analog
  • Manual paste / drag into Cursor workspace

Departments

CS, Marketing, Fraud, Payments (authors) → TDM + BA (quality) → Pods (consumers later).

Systems / MCP

Step MCP / system
List/fetch mcp-google-drive or Graph/Teams
Bytes docx/pdf/csv parsers; images → OCR
Memory AgentMemory: “this program’s DoR quirks”
Retrieve RAG col_requirements + col_decisions (collections)
Write Drive move after policy auto or PM exception; Confluence link optional

Pipeline (detail)

  1. Capture
    Hash file, store source_url, modifiedTime, owner email. If paste, flag stale-paste-risk (40).

  2. Type
    requirement / assessment / SoW / meeting-dump / unknown. Unknown → REJECT (48). Same ask as an open key → DUPLICATE (46).

  3. Safety
    PII scan (36). Token/connection string → 49. Hit → stop. OCR fail (30).

  4. Normalize
    Extract headings. Huge file (31): summarize with page cites, do not verify “the whole PDF”.

  5. Retrieve
    Similar verified PRDs for this pod; prior decisions on same metric.

  6. Rubric A–G (Doc rubric)
    Each fail → reason code + quote from source. Typical: missing-who-why missing-what missing-constraints missing-oos missing-ac. Invented AC forbidden (38).

  7. Classify
    JSON envelope (Gate). Suggest folder.

  8. Commit path (24)
    Green + policy: move /verified, then ingest RAG. REWORK: /rework/{code} and ping author (DontPassMessage). Exception list: /pm-review — PM PM-OK then /verified.

  9. Next
    Verified pack becomes input to Jira split (11).

Solution summary

One rubric, two entry ramps (auto Drive vs paste). Green auto /verified; red to author; PM exceptions. RAG only after /verified.
