20 — Case: SoW / assessment vs backlog

Problem

Assessment pack or SoW promised scope that has no epic. Delivery will fail quietly.

Trigger

New Drive assessment (10) · contract amendment · quarterly review

Departments

Vendor/mgmt · Dept Head · TDM · BA

Systems / MCP

Drive verified SoW · tracker program view · RAG col_requirements + col_jira (07.rag-architecture.md)

Components

flowchart LR
  SoW[Verified SoW clauses] --> Diff
  J[Jira epics] --> Diff
  Diff --> Gap[scope-gap]
  Gap --> Head[Lead + TDM]

Pipeline

  1. Extract deliverables from verified SoW (cites).
  2. Map to Feature/Epic keys.
  3. Unmapped clause → class TRADEOFF reason scope-gap (Gate) — commercial, not REWORK.
  4. Over-mapped (tickets not in SoW) → DEFER or CHANGE + scope-creep out-of-contract (18 47).
  5. PM + Head: add epics, descope, or change SoW (26).

Solution

Contract and board must be diffable. AI diffs; humans commercially decide.
