51 — Edge: irreversible change (always PM)

Symptom

Hard delete, prod backfill, breaking schema, drop-and-recreate, “run once on live.” A–G may look green.

Detect

irreversible flag · DDL drop · DELETE without where-key · backfill job on prod path

Flow

flowchart TD
  Ask[Change] --> Irr{Reversible?}
  Irr -->|yes| Policy[Normal 24 path]
  Irr -->|no| PM[Exception — commit_path pm]
  PM --> Lead[Lead + tech lead]
  PM --> Never[Never auto-Ready]

Solution

Quality class may be VERIFIED. Commit path is always pm. Exception flag irreversible (Gate 24). Combine with 42 if SQL write. Rollback plan on the ticket or it stays in PM_Review.
