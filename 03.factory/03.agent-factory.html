Agent factory — BIND → verify → HIL

Model: Plane B proves machine checks. Human accepts before Done (Plane C).

Pipeline shape (detail): 01.flow/06.agent-execution-pipeline.md.

Class: dev-runtime when implementing/fixing bound WBS or tracker task.

1. Preconditions (BIND)

Must have Source
Task id or tracker key WBS 00.task.md / matrix
AC + verify commands Task packet, BIP §7
Service or app boundary intake A, slice identity
Slice Leader GO or PM exception 03.slice-go-nogo.md
Pre-flight stages 1–6 not BLOCKED 01.flow/08.lifecycle/03.slice/01.pre-flight.md

BIND output in chat: cite in-pack paths, brain tier (if used), prompt class, files in WBS table.

2. Implement loop

plaintext
123456
1. Classify prompt (intake vs dev-runtime vs qc-runtime)
2. Policy brain pass (analysis) OR implementation pass (bound AC/WBS)
3. Session stamp / audit record per org agent policy
4. Only WBS-listed files
5. Security context on all tiers (org standard)
6. Transactional writes when mutating (org backend standard)

Forbidden during implement: invent contracts; tracker In Progress/Done from agent; skip named verify commands.

3. Verify (mandatory)

Run commands from task packet — org defines tooling ({build_command}, {test_command}).

Result Next
PASS QC checklist (light) → HIL handoff
FAIL fix loop (max 3× same root error) → stop + OPEN

Paste verbatim command + exit status in reply and tracker comment.

4. QC runtime (optional gate before HIL)

After verify PASS, run scenario matrix checks per ../../02.gate/00.index.md / slice QC rows:

  • Happy path
  • Missing tenant / scope
  • Invalid input DTO
  • Event / message contract if mutating
  • List/query pagination rules (if applicable)
  • UI: loading / empty / error states (if applicable)

Blocked case → name case_id / SCN — do not mark passed.

5. HIL handoff (agent stop line)

Step Action
1 Chat: READY_FOR_HUMAN_REVIEW
2 Comment on subtask (template below)
3 Labels: human-in-loop, agent-factory-pass (or org equivalent)
4 Transition → Human In Review
5 WBS Status → [HIL] HUMAN_IN_REVIEW

Forbidden after PASS: push · PR merge · Story Done · QC Done without B′ when required.

6. Human actions (Plane C boundary)

Action Owner
Review diff + AC Pod / TDM
Manual QA QC as needed
DEV Done / merge Human
Story Done rollup Human when all subtasks + DoD
Commit / PR User request only

7. Rework loop

User pastes bug after HIL → re-enter implement with bug as failure input → verify again.

8. Brain / agent unavailable

If policy requires an external reasoner and it is down: no protected writes; record outage; wait for human waiver or restore service.
