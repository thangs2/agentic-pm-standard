08 — Rubric: Jira hierarchy

Full tracker system (diagram law, Blocks, epic matrix, rollup, registry): 09.lookup/03.tracker/00.index.md.

Purpose

Feature ≠ Epic ≠ Story ≠ Subtask. Wrong layer is wrong-layer.

Layer contracts

flowchart TB
  F[Feature<br/>business outcome + metric + owner]
  E[Epic<br/>value slice still demoable]
  S[Story / Task<br/>one sprint + AC D]
  U[Subtask<br/>technical crumbs — no new AC]

  F --> E
  E --> S
  S --> U
Layer Must have Must not
Feature Why, success metric, sponsor SQL, sprint AC
Epic Slice of value, in/out “Build entire pipeline”
Story A–G in short form; sized Two pods as one owner
Subtask Parent story key; how-ish OK Own conflicting AC

Story bar (pull-ready)

Reuse document A–G compressed onto the ticket:

  • Description = B + A
  • Constraints field or first comment = C
  • AC field = D Given/When/Then
  • Out of scope section = E
  • Links / issue links = F
  • Attachments / Confluence = G

Empty AC → needs-ac. AC that is implementation → 33. Story bigger than one sprint → 34.

Classifier flow

flowchart TD
  T[Issue] --> Layer{Declared type}
  Layer --> Shape[Shape vs contract]
  Shape -->|fail| REWORK
  Shape --> Stories[If story: A-G]
  Stories --> Out[class + codes]
