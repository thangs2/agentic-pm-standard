BIP / FIP implementation packets — READY · READY-SPLIT

BIP = backend implementation packet. FIP = frontend implementation packet.

Copy to {wbs}/05.tasks/{service}/{slice}/01.bip.md or 01.fip.md. One packet, one atomic slice — not a whole service.

Status semantics

Status Meaning
DRAFT Work in progress — not for pull
OPEN Blocked on §8 item — not READY
READY-SPLIT Domain + schema + handler plan ready; HTTP or FE contract OPEN with owner — WBS must split contract subtasks
READY All planes OK or N/A — slice may Leader GO
BLOCKED Hard stop — named OPEN blocks stage 6 pre-flight
