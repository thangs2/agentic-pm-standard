Pre-flight readiness — stages 1–9

Scope: Cockpit inspection before Plane B (implement) or tracker Ready.

Rule: Walk stages 1 → 9 in order. One unchecked active checkbox for this scope → BLOCKED (no product code).

Status values (per row): READY · P (partial — gap + OPEN id) · BLOCKED · N/A (reason required).

4. Agent pre-flight run (dev-runtime, before protected writes)

  1. BIND — load 00.task.md, BIP/FIP, 06.go-nogo.md, stages 6–9 slice copy.
  2. For stages 1–7: read cited paths → emit GREEN / RED / P per row (no invention).
  3. Any stage 1–6 RED → abort implement; return evidence packet to PM.
  4. Stage 8 only when stage 6 = READY or READY-SPLIT with named OPEN and Leader DEV ≠ NO.
  5. After implement: stage 8 verify log mandatory; stage 9 = HIL handoff only.

Docs Ready ≠ slice Leader GO. Pre-flight proves artifacts exist; go-nogo is role sign-off.
