Slice Go / No-Go — BA · QC · DEV

Use: one slice = one WBS task in one primary service or one client app.

Pull / implement only if BA = GO and QC = GO and DEV = GO, or a written PM exception.

plaintext
12
Requirements → US/AC → QC matrix (planned) → BIP/FIP + WBS
  → slice Leader GO → Ready → pod In Progress → verify → QC execute (Plane B′)

Forbidden: Ready on invented HTTP/PATTERN; silent OPEN; Story Done without QC evidence.

Wave dashboard (domain cut): 02.increment/02.wave-go-nogo.md — Docs Ready ≠ slice Leader GO.

Task copy pattern: {wbs}/05.tasks/{service}/{slice}/03.slice-go-nogo.md

Verdicts

Mark Meaning
GO Role plane complete for this slice; blocking OPEN listed
P Partial — gap named; not pull unless exception
NO Missing mandatory artifact or invented contract
OUT Not this increment
N/A Plane does not apply (reason required)

Leader: GO only if BA ∩ QC ∩ DEV = GO. Else NO-GO + blocker id (OPEN id or missing artifact).

BA matrix (document-driven)

Score GO only if every row passes.

# Artifact Pass
BA-1 Requirements shard cites policy or as-built code {doc_root}/02.requirements/{domain}/
BA-2 US: actor, intent, in/out {doc_root}/03.analysis/.../us-*.md
BA-3 AC table; ≥1 failure/edge Same US shard or QC matrix
BA-4 Domain names — not screen ids as taxonomy DDD / bounded context
BA-5 Design page + ZONE if [fe] UI; else N/A [be] design trace standard
BA-6 Process flow cite if multi-step business-process overview / flow spine
BA-6a Per-US / per-step TO-BE flow shard + activity {pillar}/flows/ · no OPEN-BF-ACTIVITY on in-scope rows
BA-7 OPEN ids explicit Increment / task OPEN register
BA-8 AC not “match design mockup only” Analysis SoT

Fail BA-3 or BA-7 → NO. Missing design trace on UI US → BA P ([fe] not Ready).

QC matrix (plan before code; execute in Plane B′)

QC design is DoR. QC execute after qualified DEV Done (QC lane trigger matrix).

# Artifact Pass
QC-1 Every in-scope ac_id has ≥1 scenario_id {doc_root}/03.analysis/04.quality-control/
QC-2 ≥1 happy + ≥1 failure or edge QC scenarios law
QC-3 tenant / rbac if AC mentions isolation or permission
QC-4 OPEN → scenario blocked + OPEN id
QC-5 automated = path or manual + reason
QC-6 [qc] WBS row or TDD tdd-qc planned
QC-7 Execute evidence — not Story Done here (pod) After DEV Done

No matrix → NO for runtime slices.

DEV matrix (implementation packet)

# Artifact Pass
DEV-1 BIP/FIP status READY or READY-SPLIT (or BLOCKED with named OPEN) 01.bip.md / 01.fip.md
DEV-2 Atomic subtask table — one file per row atomic WBS rule
DEV-3 HTTP path or PATTERN cited or OPEN with owner {doc_root}/04.architecture/05.api/
DEV-4 Schema/index in owning service or N/A (FE-only) data-sync law

DEV-9 Approved stack only (no forbidden frameworks / client patterns) anti-patterns catalogue
DEV-10 Depends named; no hidden wait on another slice OPEN WBS / wave go-nogo

HTTP OPEN on this slice only → DEV NO for that ST; other slices may still GO if split.
