02b — Claude.ai nucleus (Cursor alternative)

Purpose

Swap Zone 3 only when the company standard is claude.ai, not Cursor. Zones 0–1 sources, Zone 5 gate, Zone 6 Jira/Drive/wiki do not change. Same law: 01. Same auto-Ready vs sender vs PM: 24.

Canonical Cursor stack stays in 02. This file is the company-Claude map.

Do not mix these three

Surface What it is Replaces Cursor?
claude.ai Web chat + Projects + Memory + Connectors Cockpit for a TDM day — partial
Claude Desktop Desktop app + local / org MCP Closer: same model, real pipes
Claude Code Terminal / IDE agent + MCP Yes — 1:1 cockpit swap

Company “we use Claude” usually means claude.ai. That is not Claude Code. Interview: name the surface, do not blur them.

Default operating mode on web-only: classify + draft, human or sender commits. That is Phase 0 of 24 — not a downgrade of the law, a thinner pipe.

Project instruction (paste into the TDM Project)

Keep this short. Detail stays in Confluence.

plaintext
1234567891011121314
You are the AI PM classifier for this program. You are not the source of truth.

Rubric A-G on every requirement/story: who-why, what, constraints, observable AC,
out of scope, deps, enough docs (not a novel). No cite → not VERIFIED (uncited-claim).

Classes: VERIFIED | REWORK + reason codes | REJECT | QUARANTINE | CONFLICT | BLOCKED_EXT.

Green + policy → say AUTO-READY (do not click unless write tools and policy allow).
Red → bounce to SENDER with codes and SLA, not to the TDM mailbox.
Yellow → pm-review (P0, CONFLICT, PII, new author, low confidence, bounce≥2, SoW).

Meet / transcript → MoM + Jira Intake only. Never Ready from a meeting.
Never merge. Never In Progress / Done. Never prod SQL. Never invent AC.
Never ingest unverified intake into Project knowledge.

Duplicate trusted-author list and sprint conventions into wiki. People without Claude must still run the board.

IT whitelist is the real constraint. If Jira MCP is blocked, the nucleus still classifies; destination writes wait. Do not scrape around 401 (03).

Code intelligence: Sourcegraph (or pod) — not Project knowledge. Same as parallel stack B in 02.

Interview line

Cockpit is swappable. Cursor is how I run it on my machine. Here I’d put the same operating model on Claude — a Project as the session, connectors as pipes, Jira and Confluence as source of truth. The model doesn’t own Ready. The rubric does. Code blast radius is Sourcegraph or the pod, not the chat.
