Per-system contract

MCP Dept Read Write after PM gate Never
Jira Delivery + all requestors Issues, comments, changelog Draft issue, comment, transition only if policy allows PM Done/Ready without rubric; bulk assign
Notion BA/PO/PM docs Pages, DBs Update after approve Delete production pages
Confluence Org SoT Pages, attachments Same Overwrite without version comment
Figma / Penpot Design / BA File, comments, node text Comments, not redesign Silent restyle
Google Drive Cross-dept docx, pdf, csv, images Move to /rework /verified after PM Share-wide public; PII folders
MS Teams / SharePoint Same Same Same Bypass DLP
GitHub/GitLab Dev PR, CI, diff, CODEOWNERS Comment; request reviewers Merge; push to main
Postgres MCP Analytics / Ops Replica SELECT None Prod write, DROP, PII dump into chat
Filesystem MCP Local scratch Exports Local drafts Treating local as SoT
AgentMemory PM Memories After PM OK Conflicting “facts” vs Jira
CodeGraph Dev Graph queries N/A Using graph as sprint status

Sequence: generic MCP read

sequenceDiagram
  participant PM as PM
  participant C as Cursor
  participant D as DeepSeek
  participant M as MCP
  participant S as System of record

  PM->>C: Intent (classify this PRD)
  C->>M: fetch file / issue
  M->>S: API GET
  S-->>M: payload
  M-->>C: text / metadata
  C->>D: rubric + citations only
  D-->>C: class + missing A-G
  C-->>PM: draft verdict
  PM->>C: approve / rework
  alt approve and write allowed
    C->>M: PATCH / move / comment
    M->>S: mutate
  end

Dual-cockpit rule

Claude Code may bind the same MCP servers. Session lock: one cockpit writes Jira at a time. Log actor=cursor|claude in the comment.
